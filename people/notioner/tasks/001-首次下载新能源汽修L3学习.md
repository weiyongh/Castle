# 任务 001：首次下载《新能源汽修L3学习》

## 版本

- 当前版本：1.0
- 日期：2026-09-16
- 状态：实现完成，已通过登录浏览器导出并执行首次下载

## 目标

将 Notion 页面《新能源汽修L3学习》完整同步到：

```text
Castle/assets/l3-knowledge/新能源汽修L3学习/current/
```

来源：<https://app.notion.com/p/L3-2faa4e43864980399f2cebb011f5f302>

## 简单设计

单一入口 `src/notion_sync.py` 维护笔记名称、别名、Notion page ID 与 Asset 路径的映射。

同步分为四步：

1. 使用官方 Notion API 递归读取根页面、子页面和嵌套 blocks。
2. 在同一临时版本目录中生成可读 Markdown、完整 API 原始 JSON、附件与 manifest。
3. 所有下载成功后，原子地将临时版本切换为 `current/`。
4. 普通更新先将旧 `current/` 移入 `history/<UTC时间戳>/`；首次下载若发现已有内容则拒绝覆盖。

令牌仅从环境变量读取，不写入代码、文档或 Asset。

## 产出物

- `src/notion_sync.py`：同步工具 1.0.0。
- `src/test_notion_sync.py`：导出、别名解析、归档与首次下载保护测试。
- `README.md`：维护对象、授权与调用说明。
- Asset 每个版本均包含可阅读 Markdown、子页面、附件和 `manifest.json`；
  manifest 记录来源、同步时间、数量统计、文件大小与 SHA-256。
- API 模式额外包含 `notion-export.json`，完整保存 API 原始数据。
- 浏览器模式保留 Notion 官方 Markdown/CSV 导出的原始目录和文件名。

## 授权准备

1. 在 Notion 创建 Internal Integration，并复制 token。
2. 在目标页面的连接设置中邀请该 Integration，使其可以读取页面及子页面。
3. 在执行同步的终端中设置 `NOTION_TOKEN`。

不要把 token 写进仓库文件或命令历史。可使用当前 shell 的安全凭据注入方式。

## 调用方法

在 `Castle/people/notioner/` 中执行：

```bash
python3 src/notion_sync.py download "新能源汽修L3学习"
```

后续更新指定笔记：

```bash
python3 src/notion_sync.py update "L3"
```

导入通过 Notion 浏览器界面生成的 Markdown/CSV ZIP：

```bash
python3 src/notion_sync.py import-export "L3" --zip /path/to/notion-export.zip
```

若作为后续版本导入并归档当前版本，追加 `--as-update`。

更新全部已维护笔记：

```bash
python3 src/notion_sync.py update-all
```

测试到临时或自定义 Asset 根目录：

```bash
python3 src/notion_sync.py download "L3" --asset-root /path/to/assets
```

成功时标准输出为 JSON，包含 `current`、归档位置和页面、block、附件数量。失败时标准错误输出 JSON，进程返回非零状态。
