# 牛二发现

## 发现 1：Audit 历史不能完整恢复被审旧版本

发现时间：2026-09-17 09:44 +0800  
发现者：Planner

### 问题

`_Audit.md` 可以保存每轮 Submission 的 SHA-256、Audit Result、Finding 和响应，但被审 Artifact 会被下一版本覆盖。

仅保存哈希不能保证未来仍可取得该哈希对应的原始内容，因此当前 Audit 历史可用于连续复审，但不足以支持永久、可复现、抗篡改的审计追溯。

### 当前影响

- 能证明当时记录了哪个哈希；
- 不能保证以后能恢复该哈希对应的原始版本；
- 文本署名不能提供系统级身份保证。

### 待解决

需要 Castle 确定每轮 Submission 的不可变修订保存方式，例如 Git commit、只读快照或内容寻址对象。

在正式方案确定前，不将其中任何一种技术方式视为既定规则。

### 状态

`OPEN`
